# Issue tracker

Issues and specs live in alvinxiao/task-orchestration on GitHub.
Use the gh CLI with --repo alvinxiao/task-orchestration.

Before publishing, verify the destination with gh repo view.
Create issues with --body-file for multiline Markdown.
Read tickets with gh issue view; search existing issues before creating
one to avoid duplicates. Apply labels with gh issue edit.

When a skill says to publish to the issue tracker, create a GitHub issue.
When a skill says to fetch a ticket, read its body, labels, and comments.

PRs as a request surface: no.
